# 에셋 제작 가이드 (AI 이미지 도구용 프롬프트 + 규격)

화분과 꾸미기 아이템 이미지를 AI 이미지 도구(Recraft, Adobe Firefly 등)로 만들 때 쓰는 문서다.
**이 문서대로 요청하고 파일 이름을 붙이면 코드 수정 없이 앱에 연결할 수 있다.**

> 현재 앱의 화분·얼굴은 코드로 그린 임시 그림이다 (`item_art.dart`, `decorated_pot.dart`). 아래 좌표와 크기는 가장 최근 미리보기(사다리꼴 화분)의 비율에서 계산했다.
> 여기서 만든 정식 이미지로 교체한다. 좌표는 현재 임시 화분 배치에서 계산한 값이므로, **화분(1번)을 먼저 확정한 뒤 앵커를 그 화분에 맞춰 다시 계산**한다 (앵커는 앱 상수라 개발자가 맞춘다).

## 0. 기본 원칙

| 원칙 | 내용 |
|---|---|
| UI는 AI에 맡기지 않는다 | 버튼, 카드, 진행바, 글자는 앱 코드로 만든다. AI는 **그림 부품**만 만든다 |
| 글자 금지 | 어떤 이미지에도 글자·숫자를 넣지 않는다 (기획서 3.2) |
| 부품을 따로 만든다 | 화분 / 식물 / 눈 / 입 / 볼 / 머리장식 / 배경을 **각각 별도 파일**로. 한 장에 합쳐 그리면 쓸 수 없다 |
| 투명 배경 | 배경(`bg_*`)을 제외한 모든 부품은 **투명 배경 PNG** (또는 SVG) |
| 같은 캔버스 | 모든 부품은 **같은 크기의 정사각 캔버스**에 **제자리에 그려진 채로** 낸다 (아래 2장) |
| 외곽선 없음 | 기준 이미지처럼 윤곽선 없이 면과 부드러운 그라데이션으로 표현 |
| 좌우 대칭 아이템 | 눈, 볼은 좌우 한 쌍을 한 파일에 담는다 |

## 1. 공통 스타일 블록 (모든 프롬프트 앞에 붙인다)

기준 이미지를 **스타일 참조(Style Reference)** 로 함께 올리고, 아래 문장을 모든 요청 앞에 똑같이 붙인다.
(영어로 쓰는 편이 대부분의 이미지 모델에서 결과가 안정적이다.)

```text
Cute kawaii flat vector illustration for a mobile game-like app. Soft smooth gradients,
NO outlines, clean rounded shapes, warm friendly colors. Palette: terracotta orange (#F2A671),
leaf green (#46A23E to #7FD058), soft pink blush (#FF8C98), dark brown details (#3B2A25).
Front view, centered, symmetrical. Transparent background. No text, no letters, no numbers,
no watermark, no frame.
```

**공통 금지 문구 (Negative prompt을 지원하는 도구에서는 여기에 넣는다. 없으면 본문 끝에 "Do not include ..."로 붙인다):**

```text
text, letters, numbers, outline, black stroke, 3D render, photo, realistic, harsh shadow,
background, frame, border, extra objects, watermark
```

## 2. 캔버스와 좌표 (제작 템플릿)

모든 부품은 **1020 × 1020 px 정사각 투명 캔버스**(@3x 원본)에 제자리에 그려서 낸다.
화면에서는 이 이미지를 같은 크기로 겹쳐 쌓기만 한다 (위치 보정 코드 없음).

| 내보내기 | 크기 | 폴더 |
|---|---|---|
| @3x (원본) | 1020 × 1020 | `assets/decoration/3.0x/` |
| @2x | 680 × 680 | `assets/decoration/2.0x/` |
| @1x | 340 × 340 | `assets/decoration/` |

**Figma 템플릿 만드는 법:** 1020×1020 프레임을 만들고 아래 가이드 선(guide)을 그려 둔 뒤, 모든 부품을 이 프레임 안에서 작업한다.

| 기준 | 위치 (px, 1020 캔버스 기준) |
|---|---|
| 배경 원 | 지름 1020 (캔버스 전체에 꽉 차는 원) |
| 림(테두리 띠) | x 224 ~ 796, y 530 ~ 620 (높이 약 90) |
| 몸체 윗변 | x 252 ~ 768, y = 620 |
| 몸체 아래쪽 (사다리꼴, 모서리 둥글게) | y = 867에서 x 320 ~ 700, 바닥 y = 938에서 평평한 폭 약 200 |
| 흙 타원 중심 | (510, 537) |
| 식물 줄기 시작점 | (510, 543) |
| 식물이 차지하는 높이 | y 200 ~ 543 (림 위쪽) |
| 바닥 그림자 중심 / 반지름 | (510, 955) / 가로 300, 세로 33 |

**얼굴 앵커** (화분 몸체 기준, 모두 가로 중심은 x=510):

| 부품 | 중심 위치 | 크기 (대략) |
|---|---|---|
| 눈 한 쌍 (눈썹 포함) | y = 716, 좌우 눈 중심은 x = 430 / 590 | 눈 하나 폭 약 60, 눈썹은 눈 위 약 55 |
| 코 | (510, 786) | 폭 약 40 |
| 입 | (510, 843) | 미소 폭 약 80, 활짝 웃는 입 폭 약 100 |
| 볼 한 쌍 | y = 795, x = 352 / 668 | 하나당 폭 약 90, 높이 약 55 |
| 머리장식 | (510, 515), 림 윗면에 걸쳐 놓는다 | 폭 약 300 이내 |

레이어 쌓는 순서 (아래에서 위로): 배경 → 화분 → 식물 → 볼 → 입 → 코 → 눈 → 머리장식.

## 3. 파일 이름과 폴더

**파일 이름은 앱의 아이템 id와 같게 한다** (코드가 그 이름으로 찾는다).

```
assets/decoration/
├── bg_1.png ... bg_3.png          배경
├── pot_1.png ... pot_4.png        화분(용기)
├── plant_1.png ... plant_5.png    식물 성장 단계 1~5
├── eyes_1.png ... eyes_6.png      눈(눈썹 포함)
├── nose_1.png ... nose_4.png      코
├── mouth_1.png ... mouth_6.png    입
├── cheek_1.png ... cheek_4.png    볼
├── head_1.png ... head_6.png      머리장식
├── shadow.png                     바닥 그림자
├── 2.0x/ ...                      @2x 같은 이름
└── 3.0x/ ...                      @3x 같은 이름
```

(선택) 기뻐할 때 표정을 쓰기로 하면 눈과 입에 `_happy` 버전을 추가한다: `eyes_1_happy.png`, `mouth_1_happy.png` (기본 아이템부터).

## 4. 제작 순서 (이 순서를 지키면 일관성이 훨씬 좋다)

1. **화분 1번**을 먼저 만든다 → 마음에 들 때까지 반복. 이것이 모든 부품의 기준이다.
2. 화분 1번 이미지를 **참조 이미지(Image/Style Reference)** 로 올리고 다음 부품을 만든다: 식물 → 눈 → 입 → 볼.
3. 눈·입·볼은 **기본 아이템(10종)** 부터 만든다. 해금 아이템은 나중에.
4. 각 부품은 Figma의 1020 템플릿 위에 올려 정렬을 확인한다 (화분에 얼굴을 얹어 본다).
5. 정렬이 끝나면 @1x/@2x/@3x로 내보낸다.

기본 제공 10종: `bg_1`, `pot_1`, `eyes_1`, `eyes_2`, `nose_1`, `nose_2`, `mouth_1`, `mouth_2`, `cheek_1`, `head_1`.
(코와 머리장식은 기본 상태가 "없음"이라 이미지가 없어도 앱이 동작한다.)

## 5. 부품별 프롬프트

모든 프롬프트는 **"1장 공통 스타일 블록" + 아래 본문** 순서로 쓴다. `{...}`는 바꿔 넣는 부분이다.

### 5-1. 화분 `pot_1` ~ `pot_4`

```text
[공통 스타일 블록]
A single terracotta flower pot, front view. Tapered body: wider at the top, narrower at the
rounded base. A wider rim band at the top with a thin darker line just below it. The top
opening shows a dark brown soil ellipse. Soft vertical gradient on the body, subtle. NO face,
NO plant, NO shadow. Pot color: {색}. Canvas square, pot centered horizontally, bottom of the
pot at 92% of the canvas height.
```

| id | 색 |
|---|---|
| `pot_1` (기본) | terracotta orange (#F2A671) |
| `pot_2` | warm mustard yellow |
| `pot_3` | soft teal / mint |
| `pot_4` | soft pink |

### 5-2. 식물 `plant_1` ~ `plant_5`

화분 없이 **식물만** 그린다. 줄기 시작점이 캔버스의 (510, 543)에 오도록 한다.

```text
[공통 스타일 블록]
{단계 설명}. Leaves are two-tone green with a visible darker vein line. Smooth stem, rounded
tips. NO pot, NO soil, NO face. The stem starts at the exact horizontal center and the base of
the stem is at 53% of the canvas height.
```

| id | 단계 설명 |
|---|---|
| `plant_1` | A tiny brown seed half-buried, only the top of the seed visible, very small |
| `plant_2` | A very short sprout with two small round leaves |

| `plant_4` | A taller stem with two medium leaves and a closed pink flower bud at the top |

thin curved brown lines above the eyes. The two eyes are placed symmetrically, centered
horizontally on the canvas at 70% of the canvas height, the distance between the eye centers
is about 16% of the canvas width.

### 5-9. 바닥 그림자 `shadow`

```text

width, height 6.5% of the canvas height.
```

(앱에서 화분이 튈 때 그림자가 작아지게 하려고 화분과 **별도 파일**로 둔다.)

## 7. 앱 아이콘 (별도 규격)

| 항목 | 규격 |
|---|---|

| 배경 | **투명 금지** (iOS는 투명 배경을 허용하지 않음). 단색/그라데이션으로 꽉 채운다 |

## 8. 받은 이미지 검수 체크리스트

- [ ] 배경이 완전히 투명하다 (가장자리에 흰 테두리·후광이 없다)
- [ ] 캔버스가 1020×1020 (또는 @2x 680, @1x 340)이다
- [ ] 글자·숫자가 없다
- [ ] 외곽선이 없고 기준 이미지와 같은 스타일이다
- [ ] 화분 위에 얹었을 때 얼굴이 어긋나지 않는다 (Figma 템플릿에서 확인)
- [ ] 라이트/다크 배경 두 가지에서 모두 자연스럽다
- [ ] 같은 카테고리 부품끼리 크기와 위치가 같다
- [ ] 파일 이름이 아이템 id와 같다
- [ ] 사용한 AI 도구의 **상업적 이용 약관**을 확인했다 (프롬프트, 생성 날짜, 사용 계정을 기록해 둔다)

## 9. 참고: 앱 연결 방법

파일이 준비되면 `app/assets/decoration/`에 넣고 알려주면 된다. 개발자가 `item_art.dart`의 임시 그림 대신
이미지를 불러오도록 바꾸고, 앵커·z-index 상수를 새 화분에 맞춘다. 애니메이션(화분 성장·물 붓기·개화)은
Rive 파일(`.riv`)로 따로 만들며, 그때 이 문서의 화분 규격을 기준으로 한다.
